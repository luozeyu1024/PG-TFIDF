## 1. Pipeline

```text
Gene embedding
  -> gene clustering
  -> HVG audit
  -> cell TF-IDF prerequisite construction
  -> label-specific TF-IDF analysis
  -> RNA/ADT marker analysis
  -> integrated interpretation
```

## 2. Script Usage

### `state_gene_embedding_knn_leiden_cluster.py`

Use when the gene-cluster table is absent.

```bash
python scripts/state_gene_embedding_knn_leiden_cluster.py \
  --open_path gene_embeddings.npz \
  --save_path gene_cluster_output
```

Key options include `--n_neighbors`, `--neighbor_method`, `--metric`,
`--resolution`, `--leiden_key`, `--leiden_n_iterations`, `--random_state`,
`--max_genes`, and `--ID_save`.

### `check_hvg_status.py`

Use before new TF-IDF prerequisite construction.

```bash
python scripts/check_hvg_status.py \
  --h5ad input.h5ad \
  --json hvg_status.json
```

Key options: `--h5ad`, `--expected_range`, and `--json`.

### `top_gene_cell_embedding_cluster_based_cell_cluster_vector_general.py`

Preferred TF-IDF prerequisite builder for new runs. It accepts either a
verified HVG subset or a full-gene matrix with `--hvg`.

```bash
python scripts/top_gene_cell_embedding_cluster_based_cell_cluster_vector_general.py \
  --h5ad_file input.h5ad \
  --save_path tfidf_prerequisites \
  --cluster_xlsx state_gene_knn_leiden_clusters.xlsx \
  --top_k 100 \
  --top_gene_exp 10
```

Optional arguments include `--hgnc_file`, `--max_proteins`, `--seed`, `--hvg`,
`--hvg_n_top_genes`, and gene-cluster column overrides.

### `top_gene_cell_embedding_cluster_based_cell_cluster_vector.py`

Legacy builder. It assumes an HVG-subset h5ad and requires `--drug_label`.
Use only for compatible legacy reproduction. Prefer the general builder for
new runs.

### `cell_tfidf_cluster_analysis.py`

Use after TF-IDF prerequisites exist.

Biological-label route:

```bash
python scripts/cell_tfidf_cluster_analysis.py \
  --embedding_path top_gene_cell_embedding_tfidf.npy \
  --tfidf_vocab tfidf_vocab.json \
  --cell_id_table cell_id_table.xlsx \
  --drug_label labels.xlsx \
  --save_path tfidf_analysis
```

Cluster-label route:

```bash
python scripts/cell_tfidf_cluster_analysis.py \
  --embedding_path top_gene_cell_embedding_tfidf.npy \
  --tfidf_vocab tfidf_vocab.json \
  --cell_id_table cell_id_table.xlsx \
  --cell_cluster_label clusters.xlsx \
  --cell_cluster_cols Louvain_Cluster,Kmeans_Cluster \
  --save_path tfidf_analysis
```

Key options include `--cell_id_col`, `--label_map_json`,
`--cluster_label_name`, `--cluster_num_display`, `--cmap`, and `--dpi`.

### `ADT_silhouette_and_markers_calculate.py`

Use for differential markers with existing labels. It does not perform
clustering.

```bash
python scripts/ADT_silhouette_and_markers_calculate.py \
  --save_path marker_output \
  --gse dataset_name \
  --model_name model_name \
  --open_path_rna_h5ad input.h5ad \
  --open_path_cluster_xlsx labels.xlsx \
  --cluster_cols label \
  --disable_silhouette
```

Add `--open_path_adt_h5ad adt.h5ad` for optional ADT analysis. Important
options include RNA input type and normalization, pct layers and thresholds,
PCA/silhouette controls, marker counts, DE method, correction method, and
RNA-ADT concordance options.

Parameter trap:

- `cell_tfidf_cluster_analysis.py` uses `--cell_cluster_cols`.
- `ADT_silhouette_and_markers_calculate.py` uses `--cluster_cols`.

## 3. File Relationships

| Output | Generated by | Used by |
|:---|:---|:---|
| `state_gene_knn_leiden_clusters.xlsx` | gene clustering script | TF-IDF prerequisite builder, annotation lookup |
| `top_gene_cell_embedding_tfidf.npy` | cell-vector builder | TF-IDF analysis script |
| `tfidf_vocab.json` | cell-vector builder | TF-IDF analysis script |
| `cluster_specificity*.xlsx` | TF-IDF analysis script | integrated interpretation |
| `label_cluster_profiles*.xlsx` | TF-IDF analysis script | integrated interpretation |
| `cluster_presence*.xlsx` | TF-IDF analysis script | integrated interpretation |
| `cluster_statistics*.xlsx` | TF-IDF analysis script | integrated interpretation |
| `*_markers_RNA_*.tsv` | marker script | marker interpretation |
| `*_downregulated_markers.xlsx` | marker script | marker interpretation |
| `*_comprehensive_markers.xlsx` | marker script | marker interpretation |

## 4. Result Query Map

| Question | File |
|:---|:---|
| Which gene clusters are most specific to a label? | `cluster_specificity*.xlsx` |
| What is the mean TF-IDF weight? | `label_cluster_profiles*.xlsx` |
| How frequently does a cluster appear? | `cluster_presence*.xlsx` |
| What are the cluster summary statistics? | `cluster_statistics*.xlsx` |
| Which genes are upregulated? | `*_markers_RNA_*.tsv`; rank by Wilcoxon `scores`, then interpret `logfoldchanges`. |
| Which genes are downregulated? | `*_downregulated_markers.xlsx`; confirm negative `scores` and negative `logfoldchanges`. |
| What is the exact gene-level statistic? | `*_comprehensive_markers.xlsx` |

## 5. Annotation Resources

| File | Use |
|:---|:---|
| `state_gene_knn_leiden_clusters.xlsx` | Map genes to gene clusters. |
| `state_gene_knn_leiden_clusters_cluster_function_annotations.json` | Map cluster IDs to functional descriptions. |
| `examples/annotations/` | Generic bundled annotation resources. Validate compatibility before reuse. |

If the supplied gene clusters differ from bundled annotations, regenerate or
obtain matching annotations. Do not silently assign mismatched functions.
